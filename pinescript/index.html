What you'll build, live

Three small programs, each building on the last. You type along; by the end you have working code you understand line by line.

01

Your first script

Open the Pine Editor, learn the v6 basics (variables, inputs, built-in functions) and draw your own line on a chart.

02

Conditions & alerts

Turn a condition into an alert with alertcondition(), and write alert messages that carry data like symbol, price and time.

03

Webhook → Google Sheets

Send each alert as JSON to a free Google Apps Script that writes a new row in your Sheet: a log that fills itself.
